**Website to PDF - Convert Web Pages to PDF**

**Turn any collection of web pages into a single, beautifully formatted PDF document.**

Website to PDF is a powerful yet simple browser extension that lets you capture web content exactly as it appears - with full layouts, images, colors, and text - and save it all into one convenient PDF file.

**🚀 How It Works**

1. **Click the extension icon** on any page
2. **Review the list of links** found on the page
3. **Select the pages** you want to include
4. **Click "Generate PDF"** - done!

The extension opens each selected page, captures it with pixel-perfect fidelity, merges everything into a single PDF, and automatically downloads it to your computer.

**✨ Key Features**

**🔗 Smart Link Scanner**
- Automatically detects all links, anchors, and navigation buttons on the current page
- Scans both the main page AND iframes (great for e-book readers and embedded content)
- Deduplicates links and shows useful badges (External, Button)
- Search and filter to quickly find specific links

**📂 Upload URL List**
- Can't find the links you need? Upload a simple text file with URLs (one per line)
- Perfect for pages where links are hidden behind JavaScript or cross-origin iframes
- URLs are automatically added and selected

**🎯 CSS Class Scanner**
- Enter a CSS class name to find and extract links from elements with that class
- Works with CSS modules and hashed class names (e.g., `Button---root---TwJp3`)
- Finds navigation targets from href, data-href, onclick, nested links, and more

**📄 Full-Fidelity Page Capture**
- Uses Chrome's built-in PDF engine (same as "Save as PDF")
- Preserves images, backgrounds, colors, fonts, and layouts exactly as they appear
- Captures selectable text - not just screenshots
- Handles XHTML files specially to prevent blank pages

**📥 Single Merged PDF**
- All selected pages are merged into ONE PDF file
- A4 paper size with proper margins
- Page numbers in the footer
- Automatically saved to your Downloads folder

**📊 Real-Time Progress**
- Watch the progress bar as each page is captured
- See which URL is being processed
- Cancel anytime if needed

**🖥️ Works Everywhere**
- Works on any website - news, documentation, e-books, dashboards, and more
- Supports local HTML and text files
- Compatible with Chrome and Microsoft Edge

**💡 Use Cases**

**❓ Frequently Asked Questions**

**Q: Is this extension free?**
A: Yes! It's completely free to use with no ads and no premium tiers.

**Q: Does it work on any website?**
A: Yes, it works on any http/https website. It also supports local HTML and text files.

**Q: Will the PDF look like the website?**
A: Yes! The extension uses Chrome's built-in PDF engine to capture pages with pixel-perfect fidelity - images, colors, fonts, and layouts are all preserved.

**Q: Can I select which pages to include?**
A: Absolutely! After scanning, you can select or deselect any link before generating the PDF.

**Q: How many pages can I include?**
A: There's no hard limit, but very large collections may take longer to process. We recommend starting with 10-20 pages for best results.

**Q: Does it work with pages that require login?**
A: Yes! The extension uses your current browser session, so pages you're logged into will be captured with your session.

**Q: Is my data safe?**
A: Yes. The extension runs entirely in your browser and never sends your data to any server. No tracking, no analytics, no data collection.

**Q: Does it work on Microsoft Edge?**
A: Yes! Since Edge is Chromium-based, the extension works perfectly on both Chrome and Edge.

**Q: What if a page fails to capture?**
A: The extension will show an error message and continue with the remaining pages. You can retry the failed page separately.
